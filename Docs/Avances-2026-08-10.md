# Avances y mejoras - 2026-08-14

## Resumen del dia
Se implementaron mejoras para el detalle de pacientes y se creo el flujo completo de perfiles profesionales para Administrador y Profesional.

## Detalle de paciente

### Documentos adjuntos
- Se agrego la opcion de cargar nuevos documentos desde el detalle del paciente.
- La carga permite indicar el tipo de documento y seleccionar el archivo.
- La funcionalidad esta disponible para Administrador y Profesional.
- La tarjeta de documentos ahora inicia oculta.
- El boton "Consultar documentos" funciona como alternador:
  - Abre la tarjeta al seleccionarlo.
  - La cierra al seleccionarlo nuevamente.
  - Cambia su texto a "Cerrar documentos" mientras esta abierta.
- Se sincronizo el estado de la tarjeta con el historial del navegador para que el boton de volver cierre primero la tarjeta abierta.

### Objetivos de tratamiento
- Se agrego una pestaña de objetivos por paciente.
- Se agrego el campo de objetivo general del plan de tratamiento.
- Se pueden crear objetivos especificos con:
  - Codigo automatico de referencia, por ejemplo `OBJ-001`.
  - Descripcion del objetivo.
  - Frecuencia semanal o quincenal.
  - Estado pendiente, cumplido o no cumplido.
  - Observacion y fecha de evaluacion.
- La observacion se muestra y se vuelve obligatoria cuando el objetivo se marca como no cumplido.
- La estructura deja preparado el modulo para futuras mediciones y graficos de evolucion.
- El objetivo diligenciado al crear un paciente se conserva como objetivo general.

## Modulo de profesionales del Administrador
- Se elimino la columna independiente "Cambiar estado".
- Se dejo una unica columna "Estado" con modificacion directa desde el listado.
- Se retiro el formulario global "Modificar profesional".
- Se agrego la accion "Ver detalle" para abrir el profesional en iframe.
- Se creo el detalle individual del profesional con:
  - Documento.
  - Nombre y apellido.
  - Correo.
  - Telefono.
  - Estado.
  - Fotografia.
  - Documentos adjuntos.
- El Administrador puede modificar la informacion y el estado del profesional desde el detalle.
- Se agrego carga opcional de fotografia al registrar un profesional.
- El Administrador puede cargar fotografia y documentos adicionales desde el detalle.

## Mi perfil del Profesional
- Se agrego la opcion "Mi perfil" al menu lateral del Profesional.
- El Profesional puede consultar su propia informacion en un detalle dentro del iframe.
- Puede modificar sus datos personales y cargar documentos o fotografia.
- No se muestran en este perfil:
  - Observaciones.
  - Bitacoras.
  - Informes.
  - Objetivos de pacientes.
- Se aplico control de permisos para impedir que un Profesional consulte el perfil de otro Profesional.

## Persistencia y base de datos
- Se agrego la tabla `paciente_objetivos`.
- Se agrego la columna `objetivo_general` en `pacientes`.
- Se agrego la tabla `usuario_adjuntos` para fotografias y documentos de profesionales.
- Se actualizaron el esquema inicial y las migraciones:
  - `BD/migrations/002_add_objetivos_paciente.sql`

- El modelo tambien verifica y crea las estructuras necesarias para facilitar instalaciones existentes.

## Ajustes de interfaz e iframe
- Se aprovecho mejor el ancho y alto disponible del iframe en los dashboards de Administrador y Profesional.
- Se redujeron margenes internos innecesarios en los detalles embebidos.
- Se mantuvo la navegacion flotante para volver y regresar al dashboard.
- Los detalles de pacientes y profesionales utilizan una organizacion visual consistente.
